# 🎟 Season pass — ideas only (director 19 Nov: "keep it in mind, just tease it; we design it again later")
Nothing is built. Only a teaser was posted. Design it again with the director before any code or PixelLab art.

## The first draft (discussed, not decided)
- 1 season = 30 days, 50 levels; pass points from daily / weekly missions (kills, dungeon, village raid, PvP, login) — counted on the server.
- Two rows: free (gold, potions, scrolls, mana shards, a small look every 10 levels) and premium (bought with diamonds, ~300💎 suggested):
  looks only for that season (never again later) + comfort items + some diamonds back (≤30% of the price).
- No power, nothing random. The admin opens a season in the back office.

## Look ideas (new kinds the game does not have yet; PixelLab cost estimates)
1. 👣 Glowing footprints (sakura petals / fire / frost / stardust) — VFX lite ≈ $0.005 each
2. 🐾 Small pets that walk with the hero, others see them (baby dragon, spirit fox, ghost lantern, floating crystal) — ≈ $0.3 each with 8-dir walk
3. ⚔ Spirit weapons orbiting the hero (3 glowing swords / an open spell book / fire orbs) — ≈ $0.05 each
4. 💀 Kill effects (the monster bursts into butterflies / gold coins / petals) — ≈ $0.005 each
5. 🌀 Recall / warp effects (light pillar / portal / leaf storm) — ≈ $0.005 each
6. 🪽 A season wing, e.g. "hourglass wings of time" (gold gears + flowing sand) — ≈ $0.1
7. 🖼 Season name-plate frame — drawn in code, free
