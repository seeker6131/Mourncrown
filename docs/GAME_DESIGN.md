# Eldergrove Saga — Game Design (v1)

> ⚠️ **เป้าหมายระยะยาว: เกมออนไลน์** (ผู้ใช้ย้ำ 2026-11-05) — ทุกระบบที่ทำต้องออกแบบให้ย้ายขึ้นเซิร์ฟเวอร์ได้ ดูหัวข้อ 9

แนวเกม: **Pixel Isometric Action RPG + สร้างหมู่บ้าน** (ล่า → เก็บทรัพยากร → สร้าง/อัปเกรดหมู่บ้าน → หลอมอาวุธ → รับฮีโร่เข้าทีม → บุกดันเจี้ยน → ปลดล็อกดินแดนใหม่)
ไม่ใช่ MMORPG ตีเก็บเลเวล — ความก้าวหน้ามาจาก **หมู่บ้าน + อุปกรณ์แรร์ + ทีมฮีโร่**

## 1. วงจรการเล่นหลัก (Core Loop)
1. **ออกสำรวจ** ดินแดนรอบหมู่บ้าน: ตีมอนสเตอร์ ล่าสัตว์ ตัดไม้ ขุดหิน/แร่ เก็บสมุนไพร
2. **กลับหมู่บ้าน** นำวัตถุดิบมาสร้าง/อัปเกรดอาคาร อาคารผลิตทรัพยากรเองแม้ออฟไลน์ ชาวบ้านทำงานให้เห็นจริง
3. **หลอมอุปกรณ์** ที่โรงหลอม (ยิ่งเลเวลโรงหลอมสูง ยิ่งได้ของแรร์) + **ทำอาหาร** (บัฟก่อนออกล่า)
4. **รับฮีโร่** ที่โรงเตี๊ยม ทีมสูงสุด 3 คน (ต่อสู้อัตโนมัติข้างฮีโร่หลัก) แต่ละคนใส่อุปกรณ์ได้
5. **บุกดันเจี้ยน** หลายชั้น มีบอส ดรอปของแรร์ + กุญแจ/วัตถุดิบปลดล็อกดินแดนใหม่
6. **ป้องกันหมู่บ้าน** บางคืนมอนสเตอร์บุก ต้องมีกำแพง/หอคอย/ทหารยาม (ถ้าแพ้ อาคารเสียหาย ต้องซ่อม)

## 2. ทรัพยากร
| ทรัพยากร | ได้จาก | ใช้ทำ |
|---|---|---|
| ทอง | มอนสเตอร์ ขายของ ภาษีบ้านพัก | ทุกอย่าง |
| ไม้ | ตัดต้นไม้, โรงเลื่อย | สร้างอาคาร หลอม |
| หิน | ขุดหิน, เหมืองหิน | สร้างอาคาร หลอม |
| อาหาร | ล่าสัตว์/มอนสเตอร์, ฟาร์ม, คอกสัตว์ | ค่าจ้างฮีโร่ อัปเกรดขั้นสูง ทำอาหาร |
| แร่เหล็ก (ภายหลัง) | เหมืองแร่ ดันเจี้ยน | อาวุธขั้นสูง |
| ผลึกมานา | ดรอป | ตีบวก หลอม |

## 3. อาคารในหมู่บ้าน (สร้างบนที่ดิน อัปเกรด Lv1-10)
ศาลากลาง (กำหนดจำนวนที่ดิน/เลเวลสูงสุดอาคาร) · บ้านพัก (ประชากร + ทอง) · โรงเลื่อย · เหมืองหิน · ฟาร์ม · คอกสัตว์ · ครัว · โรงหลอม · โรงเตี๊ยม · โกดัง · ตลาด · หอคอยยาม · กำแพง/ประตู · บ่อน้ำ · กิลด์ (ออนไลน์ในอนาคต)
- อาคารแต่ละแบบมีภาพ **Lv1 (เล็ก)** และ **Lv5+ (ใหญ่)**
- ฟองไอคอนลอยเหนืออาคารเมื่อมีของให้เก็บ เดินผ่านเก็บอัตโนมัติ

## 4. ฮีโร่และทีม
- ฮีโร่หลัก (ผู้เล่น) + เพื่อนร่วมทีมสูงสุด 3: **นักธนูเอลฟ์, จอมเวท, อัศวินหญิง, นักบวช, คนแคระคลั่ง**
- รับสมัครที่โรงเตี๊ยม (สุ่มระดับความแรร์ของฮีโร่ / ค่าจ้างเป็นอาหาร+ทอง)
- ฮีโร่แต่ละคนมีสกิลเฉพาะ 1-2 อัน, ใส่อุปกรณ์ได้

## 5. อุปกรณ์
ช่อง: อาวุธ, หมวก, เกราะ, ถุงมือ, รองเท้า, แหวน, สร้อย — ความแรร์ 5 ระดับ + ค่าสุ่ม (มีแล้ว)

## 6. ดินแดน (ปลดล็อกตามลำดับ)
1. **ป่าเอลเดอร์โกรฟ** (มีแล้ว) — บอส ผู้พิทักษ์ธอร์นวูด
2. **ป่าฤดูใบไม้ร่วงผีสิง** — โครงกระดูก ซอมบี้ วิญญาณ — บอส กวางยักษ์คำสาป (ล่าใหญ่)
3. **ดินแดนลาวา** — อิมพ์ไฟ โกเลมลาวา ซาลาแมนเดอร์ — บอส มังกรลาวา
4. **ภูเขาหิมะ** — หมาป่าน้ำแข็ง เยติ วิญญาณน้ำแข็ง — บอส ยักษ์น้ำแข็ง
5. **คุกใต้ดิน (ดันเจี้ยน)** — หนู แมงมุม อัศวินโครงกระดูก — บอส ราชาโครงกระดูกเขาเหล็ก

## 7. ลำดับการพัฒนา
- **เฟส 1** ทรัพยากร + ตัดไม้/ขุดหิน + ที่ดิน + อาคารผลิต + โรงหลอม  ← กำลังทำ
- **เฟส 2** ชาวบ้านทำงาน + อาคารครบชุด + ภาพอาคารใหม่
- **เฟส 3** โรงเตี๊ยม + ทีมฮีโร่
- **เฟส 4** ดันเจี้ยนหลายชั้น
- **เฟส 5** ดินแดนใหม่ + บอสล่าใหญ่
- **เฟส 6** ป้องกันหมู่บ้านกลางคืน
- **เฟส 7** ออนไลน์ + ร้านค้าเติมเงิน (หัวข้อ 10): บัญชี/เซฟคลาวด์ → กิลด์/บอสกิลด์/เมืองกิลด์ → ตลาดผู้เล่น (ต้องมีเซิร์ฟเวอร์ ดูหัวข้อ 9)

## 8. แรงจูงใจ (ทำไมต้องตีแรง / อยากได้ของแรร์) — เสนอแล้ว รอผู้ใช้ยืนยัน
- เรื่องหลัก: **คำสาปกลืนแผ่นดิน** หมู่บ้านคือที่หลบภัยสุดท้าย เป้าหมาย = ชำระทุกดินแดน (เกมมีจุดจบ)
- ตีแรง → ผ่านด่านพลังรบขั้นต่ำ → ชำระดินแดน → ได้ที่ดิน + วัตถุดิบหายาก → อัปเกรดอาคารขั้นสูง
- ช่วยชาวบ้านที่ถูกขังในดันเจี้ยน → มาเป็นช่าง/แม่ครัว/ฮีโร่ในหมู่บ้าน (ปลดล็อกอาคาร)
- กลางคืนกองทัพคำสาปบุกหมู่บ้าน → ต้องแรงพอป้องกัน ไม่งั้นอาคารพัง
- ของแรร์: ใส่ / ย่อยเป็นวัตถุดิบอัปเกรดอาคาร / ขาย / ตั้งโชว์ระดับตำนานให้บัฟถาวรทั้งหมู่บ้าน

## 9. ออนไลน์ (เป้าหมายระยะยาว — ห้ามลืม)
สิ่งที่จะมี: บัญชีผู้เล่น + เซฟบนคลาวด์, กิลด์, บอสกิลด์ (หลายคนช่วยกันตี), เมืองกิลด์สร้างร่วมกัน, แชต, จัดอันดับพลังรบ, แลกเปลี่ยน/ตลาดผู้เล่น, เยี่ยมชมหมู่บ้านเพื่อน
กติกาการพัฒนาตั้งแต่ตอนนี้ (เพื่อย้ายขึ้นออนไลน์ได้โดยไม่ต้องเขียนใหม่):
1. ตรรกะเกมอยู่ใน `src/systems/*` แบบ pure function (ไม่ผูกกับ Phaser) → นำไปรันบนเซิร์ฟเวอร์ได้ (Node/TypeScript ภาษาเดียวกัน)
2. ทุกการเปลี่ยนแปลงสำคัญ (ดรอปของ, หลอม, ตีบวก, สร้างอาคาร, ซื้อขาย) ต้องผ่านฟังก์ชันใน systems เท่านั้น → อนาคตเปลี่ยนเป็น "ส่งคำสั่งให้เซิร์ฟเวอร์ตัดสิน" (server-authoritative กันโกง)
3. การสุ่ม (ดรอป/หลอม/ตีบวก) รับ `rnd` เป็นพารามิเตอร์ → เซิร์ฟเวอร์เป็นคนสุ่ม
4. GameState เป็น JSON ล้วน มี `version` + migration → อัปโหลดเซฟเดิมขึ้นคลาวด์ได้
5. เวลาผลิตของอาคารใช้ timestamp (ไม่ใช่นับเฟรม) → เซิร์ฟเวอร์คำนวณได้
6. ไอเทมมี uid เฉพาะตัว → รองรับการแลกเปลี่ยน
7. **(ผู้ใช้ย้ำ 2026-11-09) ทุกอย่างที่ให้ของ/เงิน/EXP/ผลสุ่ม ต้องย้ายไปตัดสินที่เซิร์ฟเวอร์ทั้งหมด กันแฮก** — ไคลเอนต์ส่งแค่ "สิ่งที่ผู้เล่นทำ" (ฆ่ามอน X ด่าน N, กดสร้างอาคาร) เซิร์ฟเวอร์ตรวจความเป็นไปได้ (เวลา/ระยะ/พลัง) แล้วคำนวณผลเอง; ห้ามเชื่อตัวเลขจากไคลเอนต์; เซฟหลักอยู่บนเซิร์ฟเวอร์; ปิด debug ใน build จริง
ตัวเลือกเทคโนโลยี (เลือกตอนถึงเฟส 7, มีค่าใช้จ่ายรายเดือน): Supabase/Firebase (บัญชี+ฐานข้อมูล+realtime) หรือ Colyseus/Nakama บน VPS (เล่นพร้อมกันแบบเรียลไทม์)

## 10. การหารายได้ (ผู้พัฒนาต้องขายของในเกมได้ — ผู้ใช้ย้ำ 2026-11-05)
ต้องมีระบบออนไลน์ก่อน (ยืนยันการจ่ายเงินที่เซิร์ฟเวอร์ ไม่งั้นโกงได้)
ช่องทาง: Google Play Billing (APK บน Play Store, Google หัก 15%) / เว็บใช้ Stripe หรือ Omise (รองรับ PromptPay)
ของที่ขายได้ (แนะนำเรียงจากปลอดภัย→เสี่ยงต่อความสมดุล):
1. **ของแต่งสวยงาม**: สกินฮีโร่/อาวุธ, สกินอาคาร, ของแต่งหมู่บ้าน, เอฟเฟกต์, กรอบโปรไฟล์
2. **ความสะดวก**: ช่องกระเป๋า/โกดัง, เร่งเวลาสร้างอาคาร, AUTO ขั้นสูง, ช่องทีมฮีโร่
3. **Battle Pass รายฤดู** (ฟรี + พรีเมียม) และ **VIP รายเดือน** (โบนัสรายวัน)
4. **สกุลเงินพรีเมียม (เพชร)** ใช้ซื้อข้อ 1-3
5. **กาชาฮีโร่/กล่องสุ่ม** — ต้องแสดงอัตราดรอปชัดเจน (กฎ Google Play) ระวังเรื่องกฎหมายแต่ละประเทศ
6. ขายพลังตรงๆ (อาวุธแรร์) — ทำรายได้ง่ายแต่ทำลายสังคมเกมออนไลน์ ไม่แนะนำ
หลักการ: ของแรร์ที่แรงที่สุดต้องได้จากการเล่น (หัวใจของเกม) — เงินซื้อเวลา/ความสวย/ความสะดวก
ระบบฝั่งโค้ดที่ต้องมี: ร้านค้าเพชร, ตรวจใบเสร็จที่เซิร์ฟเวอร์, ประวัติการซื้อ, คืนเงิน/เติมของแอดมิน, แผงแอดมินสำหรับผู้พัฒนา (เพิ่ม/แก้สินค้า, ดูยอดขาย, ส่งของให้ผู้เล่น, จัดอีเวนต์)

## 11. ตัวละครหลายสาย (ผู้ใช้กำหนด 2026-11-05) — ทำแล้วในเกม
- ทุกคนเริ่มเป็น **ชาวบ้าน** ถือดาบไม้ (สกิล: ฟาดแรง)
- Lv5 คุยผู้เฒ่า → เลือกสาย: **นักดาบ / นักธนู / จอมเวท / นักบวช** (ร่าง 2)
- Lv20 ร่าง 3 (ชุดเท่ขึ้น + สกิลใหม่), Lv35 ร่าง 4 (สวยที่สุด)
- แต่ละสายมีโบนัส/สกิล/วิธีโจมตีต่างกัน (ประชิด/ยิงธนู/ยิงเวท) — `src/data/classes.ts`
- ภาพแต่ละร่าง: prompt หมวด "ร่างตัวละคร" (V0, S2-4, A2-4, M2-4, C2-4 × 7 ภาพ)

## 12. ตีกันระหว่างหมู่บ้าน / ปล้นของ (ผู้ใช้ต้องการ — ต้องออนไลน์)
- โจมตีหมู่บ้านผู้เล่นอื่นแบบ async (ไม่ต้องออนไลน์พร้อมกัน): ฝ่ายรับมีหอคอย/กำแพง/ฮีโร่ป้องกันที่ AI ควบคุม
- ชนะ → ปล้นทรัพยากรได้ส่วนหนึ่ง (ไม่ใช่ทั้งหมด, มีโกดังป้องกันของบางส่วน), โล่คุ้มครองหลังโดนปล้น
- กิลด์สงคราม, ตารางอันดับ — ทำในเฟส 7 พร้อมเซิร์ฟเวอร์

## 13. ด่าน/ดินแดน ผูกกับเลเวลและร่าง (เสนอ 2026-11-06 — รอผู้ใช้ยืนยัน)
| ช่วง | ร่าง | ดินแดน | บอส | ปลดล็อกในหมู่บ้าน |
|---|---|---|---|---|
| Lv1–5 | ชาวบ้าน | ทุ่งหญ้าเอลเดอร์โกรฟ (มีแล้ว) | — | ที่ดิน 3 แปลง |
| Lv5–15 | ร่าง 2 | ป่าเงาจันทร์ + ค่ายก็อบลิน (มีแล้ว) | ผู้พิทักษ์ธอร์นวูด | +3 แปลง, โรงหลอม Lv3 |
| Lv15–20 | ร่าง 2 | ป่าฤดูใบไม้ร่วงผีสิง | กวางยักษ์คำสาป | โรงเตี๊ยม (ทีม NPC) |
| **Lv20** | **ด่านทดสอบเลื่อนร่าง 3** (เฉพาะสาย) | | | |
| Lv20–28 | ร่าง 3 | ดินแดนลาวา | มังกรลาวา | โรงหลอม Lv5 (แก่นลาวา) |
| Lv28–35 | ร่าง 3 | ภูเขาหิมะ | ยักษ์น้ำแข็ง | บ่อน้ำร้อน (ฟื้นพลัง/บัฟ) |
| **Lv35** | **ด่านทดสอบเลื่อนร่าง 4** | | | |
| Lv35–45 | ร่าง 4 | คุกใต้ดิน 10 ชั้น | ราชาโครงกระดูกเขาเหล็ก | หอคอยยาม/กำแพงขั้นสูง |
| Lv45+ | ร่าง 4 | ใจกลางคำสาป (บอสสุดท้าย) + หอคอยคำสาปไม่รู้จบ | จอมคำสาป | สงครามกิลด์/บอสโลก (ออนไลน์) |

ด่านทดสอบเลื่อนร่าง (สอนบทบาทของสาย):
- นักดาบ: ดวล 1-1 กับแชมป์ดาบ (หลบท่าใหญ่ แล้วสวนกลับ)
- นักธนู: ล่าเป้าที่วิ่งเร็วให้ครบในเวลา
- จอมเวท: รอดคลื่นมอน 5 ระลอกด้วยสกิลวงกว้าง
- แทงค์: ปกป้องชาวบ้าน NPC จนครบเวลา

กลไกผูกโยง:
- ประตูวาร์ปแต่ละดินแดนแสดง "เลเวล/พลังรบแนะนำ" — เข้าได้แต่มอนเลเวลสูงกว่าตีเราเจ็บมาก
- ของดรอปแต่ละดินแดนเป็นขั้นอุปกรณ์ของช่วงนั้น (ต้องมีเลเวลถึงจึงใส่ได้)
- วัตถุดิบเฉพาะดินแดน (เกล็ดมังกร หินเย็น กระดูกเหล็ก) ใช้อัปเกรดอาคารขั้นสูง → ต้องกลับไปตีด่านเก่า-ใหม่สลับกัน
- จุดแพ้ทางของแต่ละสาย: โครงกระดูกกันธนู/แพ้ค้อน, ลาวาแพ้น้ำแข็ง (จอมเวท), มังกรบิน (นักธนูได้เปรียบ), เยติทุบแรง (แทงค์รับ) — ทำให้สลับร่างที่ห้องแต่งตัวมีความหมาย
- ดันเจี้ยนรายวัน 3 รอบ/วัน ระดับ ปกติ/ยาก/นรก ตามร่าง บอสการันตีของมหากาพย์
- ทรัพยากรหายากในดินแดนสูง (แร่เหล็ก คริสตัล) เก็บได้เฉพาะชุดหาทรัพยากร ซึ่งอ่อนแอ → ต้องเคลียร์มอนก่อน หรือไปเป็นปาร์ตี้ (ออนไลน์)
- กลางคืนมีมอนอีลิทแรงขึ้น ดรอปดีขึ้น

## 14. เกมระยะยาว เลเวล 100 (ผู้ใช้กำหนด 2026-11-06: "เกมกินเวลาชีวิต เล่นยาวๆ เวลหลัก 100") — แทนตารางหัวข้อ 13
- เลเวลสูงสุด 100 (ทำแล้วในโค้ด: MAX_LEVEL=100, EXP โค้งชันขึ้นหลัง Lv20) • ร่าง: ชาวบ้าน Lv1 → ร่าง 2 Lv10 → ร่าง 3 Lv40 → ร่าง 4 Lv80 (FORM_LEVEL)
- เวลาเล่นเป้าหมายโดยประมาณ: Lv1–10 ~1 ชม. • 10–40 ~25 ชม. • 40–80 ~150 ชม. • 80–100 ~300 ชม. • หลัง 100 ไม่รู้จบ

| เลเวล | ร่าง | ดินแดน (บอส) |
|---|---|---|
| 1–10 | ชาวบ้าน | ทุ่งหญ้าเอลเดอร์โกรฟ |
| 10–20 | ร่าง 2 | ป่าเงาจันทร์ + ค่ายก็อบลิน (ผู้พิทักษ์ธอร์นวูด) |
| 20–30 | ร่าง 2 | ป่าฤดูใบไม้ร่วงผีสิง (กวางยักษ์คำสาป) |
| 30–40 | ร่าง 2 | หนองน้ำพิษ (ราชินีงูพิษ) |
| **40** | **ด่านทดสอบร่าง 3** | |
| 40–50 | ร่าง 3 | ทะเลทรายซากอาณาจักร (ฟาโรห์มัมมี่) |
| 50–60 | ร่าง 3 | ดินแดนลาวา (มังกรลาวา) |
| 60–70 | ร่าง 3 | ภูเขาหิมะ (ยักษ์น้ำแข็ง) |
| 70–80 | ร่าง 3 | ป่าคริสตัลลอยฟ้า (ไฮดราคริสตัล) |
| **80** | **ด่านทดสอบร่าง 4** | |
| 80–90 | ร่าง 4 | คุกใต้ดินเหวลึก 10 ชั้น (ราชาโครงกระดูก) |
| 90–100 | ร่าง 4 | ใจกลางคำสาป (จอมคำสาป — บอสสุดท้ายของเนื้อเรื่อง) |
| 100+ | ร่าง 4 | หอคอยคำสาปไม่รู้จบ, บอสโลก, สงครามกิลด์ |

ระบบเล่นยาวหลัง Lv100 (ไม่มีวันจบ):
- **ดาวข้ามขีด (Transcend)**: EXP หลัง 100 แปลงเป็นดาว ดาวละแต้มพลังถาวรเล็กน้อย (ไม่มีเพดาน)
- **หอคอยคำสาป**: ชั้นไม่จำกัด ยากขึ้นทุกชั้น จัดอันดับผู้เล่น
- **ตีบวก +20, ความแรร์ "เทพ" (สีแดง), ชุดเซ็ตโบนัส, ค่าสุ่มรีโรลได้**
- **หมู่บ้านเลเวล 1–30** อาคารทุกหลังอัป Lv10+, สะสมของโชว์ระดับตำนาน
- **สัตว์เลี้ยง/พาหนะเลเวลอัปได้**, คอลเลกชันมอนสเตอร์ (ล่าครบได้โบนัส)
- **ฤดูกาล (Season) ทุก 2–3 เดือน**: Battle Pass, อีเวนต์, ของแต่งเฉพาะฤดู
- ออนไลน์: กิลด์, บอสกิลด์, สงครามหมู่บ้าน/ปล้น, ตลาดผู้เล่น
